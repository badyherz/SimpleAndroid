# SimpleAndroid

Small Android apps, one folder per app.

| App | Description |
| --- | --- |
| [ERICards_Collector](ERICards_Collector) | Collect and look up ERICards (emergency response cards for dangerous goods), UN numbers, ADR classes and GHS H/P statements. |

Every app is built with Kotlin and Jetpack Compose, needs Android 13 (API 33) or newer, and works offline.

## Downloads

Signed APK files are attached to the [releases](../../releases) of this repository. Download the APK on your phone and open it; Android asks once to allow installing from your browser or file manager.
