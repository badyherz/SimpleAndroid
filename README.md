# SimpleAndroid

Small Android apps, one folder per app. All apps need Android 13 (API 33) or newer and work offline.

## Apps

| App | What it does | Download |
| --- | --- | --- |
| [ERICards Collector](ERICards_Collector) | Look up and collect ERICards (emergency response cards for dangerous goods), UN numbers, ADR classes and GHS H/P statements. | [Releases of this app](https://github.com/badyherz/SimpleAndroid/releases?q=ERICards+Collector) |

## How to download an app

1. Open the **Download** link of the app in the table above. It shows only the releases of that app, the newest at the top.
2. Open the newest release and, under **Assets**, tap the file ending in `.apk`.
3. Open the downloaded file on your phone. Android asks once to allow installing apps from your browser or file manager.

Every release also contains a `.sha256` file with the checksum of the APK.
